# ↗ Perp Recap · 合约复盘

**把币安 U 本位合约成交记录放回真实行情。** 导入 CSV / ZIP，选择部分或全部币种下载合约 K 线，在图上查看买卖、加减仓和进出场。

Local-first Binance USD-M trade review. Import fills, fetch futures candles, and inspect your executions in context. Python 3.11+ · Streamlit · Plotly · SQLite · MIT.

> v0.1 是可运行的本地原型。订单类型与仓位判断都显示依据；无法确认的信息不会伪装成交易所事实。无需币安 API Key。

## 开始使用

```bash
git clone https://github.com/raphael2025/perp-recap.git
cd perp-recap
python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -e .
python -m streamlit run app.py
```

打开浏览器中的本地地址，通常为 `http://127.0.0.1:8501`。也可使用 Docker：

```bash
docker compose up --build
```

程序默认只监听本机；这是个人本地工具，没有多用户登录或公网访问控制。源码公开不等于你的记录公开。

## 四步复盘

1. **导入记录**：上传币安「合约 → 交易历史 → U 本位 → 全部 → CSV」或原始 ZIP。检查字段映射、时区、原文件排序、错误行，然后确认导入。订单历史是可选补充，不是启动条件。
2. **仓位依据**：可以采用默认的「已实现利润规则」辅助分类，或者输入已核实的期初持仓，以数量推导开平仓。双向持仓按 LONG / SHORT 独立计算。
3. **下载行情**：选择一些币种或全部已导入币种、K 线周期、日期范围。选择官方 ZIP 归档或 CCXT，已有完整区间自动跳过。
4. **图表复盘**：选择币种和某一笔成交，或按日期窗口浏览。查看成交标记、真实成交价格、成交量、订单类型来源、仓位变化及逐笔明细。

没有自己的文件时，在导入页载入 `demo`。`examples/` 中的所有交易都是虚构数据；行情下载后使用真实合约数据。

## 识别规则的边界

**成交额不是盈亏。** CSV 的「金额」不用于判断开平仓；「已实现利润」用于利润规则和一致性检查。

利润规则是特定分析口径，不是市场恒等式。严格仓位模式允许零价差平仓；非零已实现利润说明成交包含已结算的仓位，但也可能是反手成交的一部分。手续费单独保留，不直接从盈亏数值猜开平仓。

Maker / Taker 不等于 Limit / Market：限价单也可能主动成交。只有交易历史、没有订单类型时，系统可以工作，但不能凭做市商字段补造市价 / 限价标签。

以最早一笔记录之前为空仓是一项假设，不是文件证明的事实。如果记录从持仓中途开始，应提供更早记录或期初仓位。双向持仓缺少 LONG / SHORT 时不能可靠重建。新成交导入可能改变历史起点，因此会清除旧期初设定；如果在导入页启用了利润规则，则重新建立并明确标记空仓假设。

无成交 ID 的内容去重无法彻底解决部分重叠导出、不同格式重导或手续费修订的问题；请核对导入统计。时区选错后的重导会触发同 ID 数据冲突，避免悄悄移动历史交易。

## 行情、内存与来源

- 只使用 `futures/um` 归档和 USD-M 合约接口，不以现货价格补空。
- 官方归档批量落盘；CCXT 按窗口分页落盘。两者共享 `(symbol, interval, open_time)` 缓存键，不会重复累加行情。
- 后台完整存储与前台窗口加载相互独立。每次图表最多 8,000 根；拖动仅作用于已载入窗口，日期 / 前后窗口按钮读取其他区间。**v0.1 尚未实现拖到边缘自动补读**。
- 单币种单次下载范围最多 50 万根；更长历史请调整周期或分批选择日期。官方月包可能包含所选日期之外的同月数据，这些只落盘，不全送入图表。
- CSV 上传上限 50 MB；交易 ZIP 解压总量上限 100 MB。交易导入预览和该账户成交还原目前在内存中运行；v0.1 不是百万成交规模的流式导入器。行情历史不会整体载入内存。
- 缺口不会填成平价 K 线，未收盘 K 线不永久缓存。停牌、下架、上市前区间、归档尚未生成会显示缺口。CCXT 能获取的历史受币安端点及网络可达性限制。
- v0.1 包含 OHLCV、计价币成交额、成交笔数、主动买入量；资金费率、标记价格、OI、资金流水和持仓历史导入列入后续计划。

## 数据与隐私

默认数据在 `data/recap.sqlite3`，官方 ZIP 在 `data/archives/`。设置 `PERP_RECAP_DB` 可选择数据库位置。备份时停止程序并复制整个 `data/` 目录。个人文件、数据库、归档及 `.env` 都已被 `.gitignore` 排除。

无第三方分析服务、无私人交易 API、无自动交易。用户点击下载时，币种和时间范围会发送给币安公开行情服务；个人成交文件不发送给币安或其他服务。Streamlit 使用统计已关闭。不同账户请使用不同本地账户名称。
