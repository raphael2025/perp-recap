# 数据与判断口径

## 币安中文交易历史字段

| 源字段 | 标准字段 | 用途 |
| --- | --- | --- |
| 时间 | time | 结合导出时区转换 UTC |
| 代币名称/币种名称/币对 | symbol | 选择正确的 U 本位合约 |
| 方向 | side | BUY / SELL；不等于 LONG / SHORT |
| 价格、数量 | price, quantity | 真实成交点与仓位增减 |
| 金额 | 不参与仓位分类 | 成交额，不是盈利 |
| 手续费 | fee, fee_asset | 支持 `0.001USDT` 后缀，保留原币种 |
| 已实现利润 | realized_pnl | 原始已结算盈亏，利润规则输入 |
| 做市商 | liquidity | 仅保留角色，不推断订单类型 |
| 交易 ID | trade_id | 去重及同币种同刻排序，保留大整数精度 |
| 订单编号 | order_id | 可选订单历史关联键 |
| 用户ID、买家 | 不持久化 | 用户 ID 仅检查是否混入多账户；方向使用明确的 BUY / SELL |

其他表头可通过界面字段映射导入，未识别的行在确认前报错，不静默丢弃。

## 利润规则与仓位算法并存

利润规则是用户选择的启发式分类：

- 已实现利润恰好等于 0：开仓 / 加仓组。
- 已实现利润大于或小于 0：减仓 / 平仓组。
- 缺失：未知，不替换为零。

该标签单独保存为派生展示字段。严格仓位模式不采用「0 必然开仓」这一推断，仍根据持仓数量区分零盈亏的平仓。利润模式与数量冲突时保留规则分类，但不继续编造仓位。

设成交前单向持仓 `q`，买入数量为正增量 `d`，卖出为负增量：

| 条件 | 结果 |
| --- | --- |
| q = 0 | 按 d 方向开多 / 开空 |
| q 与 d 同号 | 加多 / 加空 |
| q 与 d 异号，abs(d) < abs(q) | 减多 / 减空 |
| q 与 d 异号，abs(d) = abs(q) | 平多 / 平空 |
| q 与 d 异号，abs(d) > abs(q) | 一笔成交拆为平原仓、开反向余量 |

双向模式中 LONG 和 SHORT 独立计算，禁止 LONG 变负或 SHORT 变正。未确认起点的序列不能凭第一笔买卖确定真实仓位；用户可明确选择空仓假设。缺少记录造成矛盾后，该序列保持待核对，直到补充资料重算。

## 订单类型

原始成交字段优先，订单补充以账户 + 交易对 + 订单 ID 精确匹配；冲突显示未知并注明冲突，绝不按近似时间和价格猜匹配。支持 Market、Limit、止损、止盈、跟踪止损、强平等已明确枚举。无字段不猜测。

## 去重与错误处理

有成交 ID：键为本地账户 + 交易对 + 成交 ID。同 ID 内容变更是冲突，整批事务回滚。不同账户互不影响。

无 ID：规范内容散列 + 同文件出现次数；保留同文件内合法的重复内容。这是尽力而为的策略，对格式变更和部分重叠没有完美保证。界面提示用户核对。

原始 ZIP 不解压到任意用户路径。交易 ZIP 大小、分片数有上限。个人上传仅存标准化数据，不将 UID 原文保留为项目样本。

## 金额展示

价格与数量用 Decimal 计算。手续费可正可负（返佣），保留资产类型。不同手续费资产不简单相加；资金费流水缺失时不宣称已得到最终净收益。公开资金费率不是个人实际收付金额。
