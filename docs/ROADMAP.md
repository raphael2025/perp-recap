# 路线图

## v0.1 已交付

CSV / ZIP 导入、中文币安表头、导入时区与显示时区、顺序检查、订单历史补充、利润规则与仓位推导、官方 ZIP / CCXT 行情、流式行情入库、当前窗口图表、缺口提示及导出。

## v0.2 优先

- 将同订单的多次部分成交折叠，展开查看每次成交。
- 图表边缘拖动自动查询相邻窗口，前端缓存设置硬上限。
- 成交导入改为磁盘暂存、流式解析；仓位按币种增量计算，支持更大账户历史。
- 后台下载任务、暂停 / 取消、断点、按数据源报告上市与下架区间。
- 更多订单历史导出格式和字段映射模板；账户内导入批次审计与可撤销导入。
- 固定偏移之外的 IANA 时区与夏令时歧义确认。

## v0.3 待真实字段验证

- 资金流水导入：资金费、返佣、转账分开，计算可核对的净收益。
- 持仓历史导入：核对开平周期、辅助期初仓位，不能把区间汇总误当逐笔成交。
- 标记价格、历史资金费率、OI 与主动买卖副图；显示数据覆盖限制。
- 逐笔笔记、截图、标签、持仓周期复盘与多周期同步。

## 暂不做

实盘下单、自动交易、为缺失字段生成虚假事实、用现货替代合约行情、将个人成交自动上传到云端。
